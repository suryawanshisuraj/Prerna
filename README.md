# Prerna 💕 — Happy Girlfriend Day Journal

A MERN full-stack continuous digital journal created with love by **Suraj** for **Prerna**.

## ✨ Features
- **Hero Section:** Rotating 3D WebGL heart canvas, relationship counter starting **19/11/2025**, and featured Polaroid photo.
- **Our Story Timeline:** Interactive timeline cards including *The Math Assignment Excuse* and *Sea Breeze & City Lights*.
- **Photo Gallery:** Asymmetric Bento Grid featuring 15 real photos with an interactive full-screen Lightbox modal.
- **Reasons I Love You:** 10 interactive 3D 180° flip-cards with custom notes.
- **The Love Quiz:** 5 interactive trivia questions with confetti celebrations.
- **For Your Eyes Only:** Passcode-unlocked secret handwritten letter (`passcode: 2128`) featuring automatic dynamic date formatting.
- **Background Music Player:** Welcome Intro Gate modal starting background song `https://youtu.be/Bu2JHWqO6Qc`.

## 🚀 Tech Stack
- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons, Three.js, Canvas Confetti
- **Backend:** Node.js, Express.js REST API
